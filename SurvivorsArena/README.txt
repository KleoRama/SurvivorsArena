SURVIVORS ARENA

COMPILAZIONE E AVVIO (Visual Studio 2022)
-----------------------------------------
1. Aprire "SurvivorsArena.sln" con Visual Studio 2022.
2. Se necessario, ripristinare il pacchetto NuGet di GLM
3. Impostare la configurazione su "Debug" (o "Release") e la piattaforma su "x64".
4. Compilare e avviare il programma con F5 (oppure Ctrl+F5).


CONTROLLI
---------
- Schermata iniziale / Game Over:
    Pulsanti a schermo "Inizia gioco" / "Ricomincia" / "Esci dal gioco".

- In partita:
    W, A, S, D (o Frecce)         : Movimento del personaggio
    Mouse                         : Mira e rotazione della balestra
    Click sinistro (o Spazio)     : Sparo
    F1                            : Apri / chiudi menu Debug e Statistiche (slider parametri, Wireframe, Reset)
    ESC                           : Esci dall'applicazione
